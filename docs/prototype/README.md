# Прототип сайта persona (v112)

Кликабельный прототип, по которому автор утвердил дизайн сайта 2026-11-25. Сохранён как образец поведения: как
выглядит, движется и звучит каждая вкладка.

- Итоговый дизайн — `../superpowers/specs/2026-11-25-persona-final-design.md`. Там же сказано, где прав документ,
  где прототип и чем сайт намеренно отличается от прототипа.
- Журнал решений — `../superpowers/specs/2026-10-25-persona-design.md`.

## Как открыть

Из этой папки запустить любой статический сервер и открыть страницу в браузере:

```
python -m http.server 8000
```

и затем `http://localhost:8000/`. Напрямую из файла (`file://`) звук и часть скриптов не работают.

Над прототипом панель: «Движение» (обычное или упрощённое, как у посетителя с «уменьшить движение»; выбор
применяется перезагрузкой) и «Экран» (телефон, телефон горизонтально, компьютер).

## Что здесь

- `index.html` — рамка визуального компаньона brainstorming (из плагина superpowers) с прототипом внутри, как его
  показывал компаньон; картинки берутся из `files/`. Скрипты и стили прототипа — внутри этого файла.
- `files/` — картинки: логотипы, кадры карусели, миниатюры, портрет (уменьшен до 1200 px; оригинал —
  `D:\media-pool\affinity-projects\sxm-about\sxm-portrait.JPG`).
- `tools/` — скрипты на Python, которыми готовились материалы: `mc_logo_b.py` (логотип Metta Corpse: прозрачность
  по яркости, края гаснут), `theme_loop.py` (бесшовная петля темы: конец наложен на начало равномощным переходом),
  `mc_compose.py` (черновики композиций Metta Corpse), `logos.py`.
- `picks/` — копии выбора автора: шрифты, музыка, звуки интерфейса и неона, пары шрифтов, избранное галерей.

## Чего здесь нет

- Темы Metta Corpse: WAV на 75 МБ. Мастер — `D:\media-pool\davinci-projects\metta-corpse-theme\metta-corpse-theme-loop.wav`;
  чтобы она играла, положить его 16-битную копию как `files/metta-theme-loop.wav`.
- Локальных копий тем `files/theme-sxm.mp3`, `theme-etudes.mp3`, `theme-base.ogg`: без них темы играют прямо с
  Incompetech и OpenGameArt, тема вкладки из-за стены у них звучит просто тише, без фильтра.
- Остальное грузится с чужих сайтов: шрифты с Google Fonts, звуки интерфейса, неона и стирания — с Freesound, гифки
  Études — с GitHub. Если там что-то пропадёт, эта часть прототипа замолчит или опустеет.

В прототипе остался код и отвергнутых вариантов. Решения — только те, что стоят атрибутами на `.px` и страницах
(список — в итоговом документе, раздел «Переносится из прототипа»).
